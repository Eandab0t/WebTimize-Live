# WebTimize Live Privacy Policy

**Last updated:** 2026-11-09

WebTimize Live is a browser extension that applies tested, reversible page cleanup and layout settings on supported websites.

## What data is stored

WebTimize Live stores user preferences in the browser's `storage.sync` area:

- global enabled and feature settings;
- per-site feature overrides;
- exception domain names; and
- a settings schema version used for migrations.

These preferences do not include page content, passwords, form entries, browsing history, URLs with paths or query strings, analytics identifiers, or advertising identifiers.

## How data is stored and synchronized

The extension does not operate a server and does not independently transmit stored preferences. If browser synchronization is enabled, the browser may synchronize these preferences through the user's browser account. That synchronization is controlled by the browser and its account settings.

## How the extension uses website access

The extension reads the active site's hostname to determine whether a tested profile applies. On supported domains, it applies the selected profile's local styles and, only when the user enables the option and a profile provides rules, profile-defined network rules. The extension does not send page content to WebTimize.

## Third-party services

WebTimize Live does not use analytics, advertising services, remote code, an external API, or a WebTimize-operated service.

## Data sharing

WebTimize Live does not sell or share user data with third parties. Browser synchronization remains subject to the user's browser provider and account settings.

## Data retention and deletion

Preferences remain until the user changes or resets them, clears the extension's browser data, or uninstalls the extension. The Options page provides controls to restore site defaults and remove exceptions. Browser sync copies are governed by the user's browser account settings.

## Changes to this policy

This policy will be updated if the extension's data practices change. The date at the top identifies the current version.

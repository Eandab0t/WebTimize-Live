Privacy and limits

Settings stay in browser sync storage. Profiles are local extension files. WebTimize Live sends no browsing data anywhere and does not run remote JavaScript.

It cannot rewrite every website response, hide every advertisement, or guarantee that a site's layout will never change. Profiles are versioned and can be disabled at any time.
